# Cabo de Guerra do MMC

Jogo de MMC (mínimo múltiplo comum) em forma de cabo de guerra. Acertou a pergunta, ganha força; depois, na batalha, clica rápido (ou aperta ESPAÇO) para puxar a corda.

Modos:
- **Modo turma**: o professor cria a sala e projeta; os alunos entram com o código e a turma vira Time Azul x Time Vermelho.
- **Sala online**: duelo entre dois computadores.
- **Contra o computador** e **2 jogadores no mesmo aparelho**.

O online usa o mesmo Firebase da Batalha Matemática (salas/<código de 4>, campos `tipo` e `bp/`).

Jogue em: https://tiodanilo.github.io/batalha-matematica/cabo-de-guerra-mmc/
